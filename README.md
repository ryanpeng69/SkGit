# SkGit
SkGit is a [Skript](https://github.com/SkriptLang/Skript) addon that adds git support.

No git installation required, suitable for both local host and host provider.

## Requirements

Syntax of SkGit are registered using [SKR](https://github.com/ShaneBeee/SkriptRegistration),
which requires [Skript](https://github.com/SkriptLang/Skript) of version `2.15` or above.

Server version depends on [Skript](https://github.com/SkriptLang/Skript) version,
the least requirement for `2.15` is `1.21`.

Tested minecraft versions: `1.21.11`, `26.3`

TLDR: [Skript](https://github.com/SkriptLang/Skript) 2.15+

## Documentations

For syntax documentation, see [SkriptHub](https://skripthub.net/docs/?addon=SkGit) or [SkDocs](https://skdocs.org/docs?addon=SkGit).

For other information, see [wiki](https://github.com/ryanpeng69/SkGit/wiki).
