# SkGit
SkGit is a [Skript](https://github.com/SkriptLang/Skript) addon that adds git support. 

No git installation needed, suitable for both local host and host provider.

## Requirements

Syntax of SkGit are registered using [SKR](https://github.com/ShaneBeee/SkriptRegistration), 
which requires [Skript](https://github.com/SkriptLang/Skript) of version `2.15` or above.

Server version depends on [Skript](https://github.com/SkriptLang/Skript) version, 
the least requirement for `2.15` is `1.21`.

**Plugins**: Skript

For syntax documentation, see [SkriptHub](https://skripthub.net/docs/?addon=SkGit).
